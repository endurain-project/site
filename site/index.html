Why it exists

Built by a wannabe triathlete who wanted to know when to change the chain

Endurain started as a personal project. I'm an amateur triathlete with more bikes and running shoes than I'd like to admit, and I wanted one place to log every session and see how much wear each of them had taken, down to the chain and the cleats. I also wanted that history on my own server, not someone else's.

It grew from there: multiple users, Strava and Garmin sync, goals, single sign-on, a mobile app and translations into 30 languages. It's still built in spare time, by me and a small group of contributors, and I'm still learning as I go.

João Vitória Silva Maintainer · @joaovitoriasilva

What it does

A complete training log with the integrations you'd expect from the big platforms, running on hardware you own.

The feature it started with

Gear tracking, down to the last component

Add your bikes, shoes, wetsuits, skis or racquets, then the parts on them: chain, cassette, tyres, brake pads, cleats, insoles, even the laces. Give each part a wear limit and Endurain keeps count as the kilometres and hours add up.

  • Activity tracking

    Feeds, maps, laps and weekly or monthly totals for every sport.

  • Strava and Garmin

    Sync activities, gear and body composition from Strava and Garmin Connect.

  • Import files

    Upload .fit, .gpx or .tcx files one at a time or in bulk. .fit if you have the choice.

  • Health metrics

    Sleep, weight, steps, resting heart rate, fasting and water intake. Yes, even bowel movements.

  • Goals

    Set distance or time goals and check your progress week by week.

  • Multi-user and followers

    Admin and user roles, follower feeds and public profile pages.

  • MFA and SSO

    Two-factor login with TOTP, single sign-on through any OpenID Connect provider, and email verification.

  • Localized and themed

    30 languages, metric or imperial units, light or dark theme.

iOS and Android, in public beta

Record straight to your own server

The app tracks runs, rides, walks and hikes live on a map and uploads them to your own Endurain server. No signal on the trail? It keeps recording offline and syncs when you're back in range. Sign in with SSO and two-factor, same as on the web.

Self-host it

Run it yourself

Endurain is one Docker image plus PostgreSQL, configured with environment variables. If you've run anything with docker compose before, this will feel familiar.

  1. 1 Copy the example compose and env files
  2. 2 Set your secrets and integration keys
  3. 3
    Create the data folders, owned by UID 1000
    $ sudo mkdir -p /var/opt/endurain/backend/{data,logs}
    $ sudo chown -R 1000:1000 /var/opt/endurain/backend
  4. 4 docker compose up -d
Getting started guide Try the demo first
docker-compose.yml Show Hide 
services:
  endurain:
    container_name: endurain-app
    image: ghcr.io/endurain-project/endurain:latest
    env_file:
      - .env
    volumes:
      - ${LOCAL_PATH:-/var/opt/endurain}/backend/data:/app/backend/data:Z
      - ${LOCAL_PATH:-/var/opt/endurain}/backend/logs:/app/backend/logs:Z
    ports:
      - "8080:8080"
    depends_on:
      postgres:
        condition: service_healthy
    restart: unless-stopped

  postgres:
    image: docker.io/postgres:18@sha256:74935e72241653ca55e0414067e6d8763aceb8a810eb51b452253ec3dcfc4336
    container_name: endurain-postgres
    env_file:
      - .env
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U endurain"]
      interval: 5s
      timeout: 5s
      retries: 5
    volumes:
      - ${LOCAL_PATH:-/var/opt/endurain}/postgres:/var/lib/postgresql/data:Z
    restart: unless-stopped
.env Show Hide 
DB_PASSWORD=changeme
# Must be the same as DB_PASSWORD
POSTGRES_PASSWORD=changeme
# Generate with: openssl rand -hex 32
SECRET_KEY=changeme
# Generate with: openssl rand -base64 32
FERNET_KEY=changeme
TZ=Europe/Lisbon
ENDURAIN_HOST=https://endurain.example.com
BEHIND_PROXY=true

# If you change this, you also have to change DB_DATABASE
POSTGRES_DB=endurain
# Uncomment and set it to the same as POSTGRES_DB if you change it
# DB_DATABASE=endurain
# If you change this, you also have to change DB_USER
POSTGRES_USER=endurain
# Uncomment and set it to the same as POSTGRES_USER if you change it
# DB_USER=endurain
PGDATA=/var/lib/postgresql/data/pgdata

These files are examples only. Replace the placeholder secrets and adjust paths and ports for your setup. Need help? Check docs.endurain.com.

You can generate SECRET_KEY and FERNET_KEY at docs.endurain.com/tools/.

Login needs ENDURAIN_HOST to match the address you open, so serve Endurain through a reverse proxy with HTTPS. Plain HTTP on port 8080 will not let you log in with the provided example.
